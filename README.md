# ptwmd — 리서치 슬라이드

조사한 자료(글·사진·링크)를 붙여넣어 PPT처럼 정리하는 웹 편집기입니다. 설치 없이 브라우저에서 바로 사용합니다.

## 기능
- 16가지 레이아웃: 사진+핵심, 풀 사진, 강한 문장, 링크 카드 4개, 링크 보드 6개, 사진 갤러리, 핵심 수치 등
- 미니멀 테마 5종: 화이트 · 그레이 · 블랙 · 블루 · 모노
- 사진 칸: 클릭해서 선택 · 끌어다 놓기 · Ctrl+V 붙여넣기
- 링크: Ctrl+K로 웹 주소 또는 다른 슬라이드에 연결, Ctrl+클릭으로 열기
- F5 발표 모드, PDF 저장/인쇄, .json 파일로 저장·불러오기
- 작업 내용은 브라우저(IndexedDB)에 자동 저장

## 사용
`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속하세요.
